# Slow and Fast Pointer Pattern

The Slow and Fast Pointer pattern is mainly used with linked lists
to detect cycles or find specific positions efficiently.

This approach uses two pointers moving at different speeds,
which helps reduce time complexity in many problems.

Common use cases:
- cycle detection in linked lists
- finding the middle of a linked list
- problems involving repeated traversal

This folder contains problems solved as part of a
100-day pattern-based DSA learning journey.
