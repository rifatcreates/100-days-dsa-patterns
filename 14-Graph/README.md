# Graph

Graph is a data structure used to represent relationships between different nodes or points.

It works by connecting nodes through edges, allowing traversal using techniques like BFS and DFS.

It works by exploring nodes and their connections step by step using traversal algorithms.

Common use cases:
- graph traversal using BFS and DFS
- shortest path problems
- connected components
- cycle detection in graphs
- grid based problems
