# Prefix & Suffix Sum Pattern

Prefix Sum is used to precompute cumulative sums of an array
to answer range sum or subarray sum queries efficiently.

Suffix Sum works similarly, but cumulative sums are calculated
from the right side of the array.

Both techniques help optimize brute-force solutions.

Common use cases:
- range sum queries
- subarray sum problems
- finding pivot or balance index
- problems involving cumulative sums
