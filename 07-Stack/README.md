# Stack Pattern

Stack is a linear data structure that follows the
Last In First Out (LIFO) principle.

It is often used to keep track of elements where
the most recent operation needs to be processed first.

Common use cases:
- removing adjacent elements
- parentheses validation
- monotonic stack problems
- undo / backtracking logic

This folder contains problems solved as part of a
100-day pattern-based DSA learning journey.
