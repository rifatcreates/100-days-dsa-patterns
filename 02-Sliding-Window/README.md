# Sliding Window Pattern

The Sliding Window pattern is used to work with subarrays or substrings
by maintaining a moving window over the data.

Instead of recalculating for every range, the window slides forward
to optimize time complexity.

Common use cases:
- subarray sum / average
- longest or shortest substring
- fixed-size or variable-size window problems

This folder contains Sliding Window problems solved as part of a
100-day pattern-based DSA learning journey.
