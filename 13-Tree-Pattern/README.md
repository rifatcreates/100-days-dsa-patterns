# Tree Pattern

Tree is a hierarchical data structure where elements are connected in parent-child relationships.

It is widely used in many DSA problems, including Binary Trees and Binary Search Trees, for efficient searching, traversal, and data organization.

It works by organizing data in nodes connected through edges, allowing recursive traversal such as inorder, preorder, and postorder.

Common use cases:
- binary tree traversal problems
- binary search tree operations
- hierarchical data representation
- path and depth related problems
- recursive tree exploration problems
