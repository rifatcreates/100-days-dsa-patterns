# Binary Search Pattern

Binary Search is used to find an element or answer
in a sorted search space efficiently.

It works by repeatedly dividing the search range
into half and eliminating one side each step.

Common use cases:
- search in sorted array
- first / last occurrence
- ceil / floor value
- answer search on range (binary search on answer)

This folder contains problems solved as part of a
100-day pattern-based DSA learning journey.
