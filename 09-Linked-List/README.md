# Linked List Pattern

Linked List pattern focuses on solving problems where
nodes are connected using pointers instead of indexes.

It helps handle dynamic data structures efficiently
and is commonly used for in-place modifications.

Common use cases:
- reversing linked list (full or partial)
- node swapping or reordering
- sublist reversal
- pointer manipulation problems

This folder contains problems solved as part of a
100-day pattern-based DSA learning journey.
