# Heap Pattern

Heap is a data structure used to efficiently access
the smallest or largest element in a collection.

It works by maintaining elements in a special tree-based
structure where priority (min or max) is preserved.

Common use cases:
- kth largest / smallest element
- top k frequent elements
- priority based problems
- merging sorted data efficiently
- streaming or dynamic data problems

This folder contains problems solved as part of a
100-day pattern-based DSA learning journey.
