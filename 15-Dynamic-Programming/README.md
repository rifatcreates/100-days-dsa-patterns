# Dynamic Programming Pattern

Dynamic Programming is a problem solving technique used to break complex problems into smaller repeated subproblems.

It works by storing previously computed results and reusing them to avoid repeated calculations.

Common use cases:
- fibonacci type problems
- climbing stairs problems
- knapsack style problems
- longest subsequence problems
- minimum or maximum path problems
